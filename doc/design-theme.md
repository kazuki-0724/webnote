# WebNote デザインテーマ

## 1. 目的

このドキュメントは、WebNote の UI を一貫させるための設計テーマを定義した参照資料です。新しい画面、コンポーネント、パーツを作るときは、ここに定義されたルールを優先して実装してください。

> ルール: 新規 UI を追加・修正する前に、このドキュメントを必ず確認し、既存の見た目と色・余白・形状・操作感が衝突しないようにしてください。

## 2. デザインの基本思想

WebNote は「ノートを書く・整理する・戻る」という行為を、気を散らさずに素早く行えることを重視するアプリです。

- すっきりした視認性
- 作業に集中できる余白と背景
- 低い視線負荷の柔らかいグレーとブルー系
- 気持ちよく閉じる「軽い透明感」
- すべての操作が「見えやすく」「触りやすい」こと

デザインのトーンは、ビジネス向けの清潔さと、ノートアプリのやわらかさを両立した「柔らかいシステム感」です。

## 3. カラーパレット

### 3.1 基本カラー

- 背景: `slate-50` を基本とし、全体の土台として使う
- 画面の奥行き: `slate-100` でやや深い面を作る
- 主要テキスト: `slate-800` と `slate-700` を使う
- 補助テキスト: `slate-500` と `slate-400` を使う
- 強調色: `sky-500` / `sky-600` をアクセントに使用する
- ホバー時の強調: `sky-50` / `sky-100` を使う
- 境界線: `slate-200` を中心に、半透明の `white/50` も活用する

### 3.2 推奨クラス

以下の Tailwind クラスを優先して使ってください。

- 背景: `bg-slate-50`, `bg-slate-100`, `bg-white`, `bg-white/90`, `bg-sky-50`, `bg-sky-100`
- テキスト: `text-slate-800`, `text-slate-700`, `text-slate-600`, `text-slate-500`, `text-sky-600`
- ボーダー: `border-slate-200`, `border-slate-300`, `border-white/50`, `border-white/80`
- アクセント: `bg-sky-500`, `bg-sky-600`, `text-sky-600`, `ring-sky-300`, `hover:bg-sky-50`

### 3.3 禁止・回避ルール

- 目立ちすぎる赤・紫・緑の強色を新しいテーマに入れない
- 既存のスケールから大きく逸脱する鮮やかなカラーを断定的に使わない
- 黒一色の濃いダークテーマに寄せない
- 白背景に対して低コントラストな文字を使わない

## 4. 形状とレイアウト

### 4.1 角丸

- 画面レイヤー: `rounded-3xl`
- 操作ボタン: `rounded-xl`
- 小さな入力項目: `rounded-xl`
- 重要カードやモーダル: `rounded-2xl` 〜 `rounded-3xl`

### 4.2 余白

- 広めの余白を取って、見た目をやわらかく保つ
- 画面の見出しとコンテンツの間隔は詰めすぎない
- クリック可能な UI は「小さく気持ちよい余白」を確保する

### 4.3 影

- 影は強くしすぎず、軽いソフトシャドウを基本とする
- 推奨: `shadow-[0_20px_60px_rgba(15,23,42,0.08)]` のような控えめな印象
- `shadow-sm`, `shadow-md` を適度に使う
- 立体感は必要最小限に留める

### 4.4 透明感

- `bg-white/90`, `bg-white/70` を使って、背景とUIの境界をやや柔らかくする
- `backdrop-blur-sm` や `backdrop-blur-md` を使って、視覚的な軽さを演出する
- ただし「過度なガラス感」は避け、読みやすさを優先する

## 5. タイポグラフィ

- フォント: `Inter` を基本、英字には最適
- 日本語の表示には `sans-serif` 系のフォールバックを使う
- 太字は見出しや主要項目に限定し、長文には中太/通常を優先する
- 文字サイズは控えめに揃え、情報密度を高くしすぎない

### 代表的な使い分け

- 見出し: `text-lg font-semibold` 〜 `text-xl font-bold`
- 主要ラベル: `text-sm font-medium` 〜 `text-[15px] font-medium`
- 補助テキスト: `text-xs` 〜 `text-sm`
- 操作ボタン: `text-sm font-semibold`

## 6. インタラクションのルール

### 6.1 ホバー / フォーカス

- `hover:bg-slate-100` や `hover:bg-sky-50` を使って、視覚的な反応を作る
- `focus:ring-2 focus:ring-sky-300` でキーボード操作時の指示を明確にする
- 無駄なアニメーションは避け、軽い `transition-colors` を基本とする

### 6.2 モーダルとダイアログ

- 背景オーバーレイは控えめな透明感を保つ
- フォーカス制御と視認性を重視する
- モーダルのボタンは、主要操作と副次操作の違いが明確になるようにする

### 6.3 状態表現

- 活性: 明るい背景と鮮やかな青のアクセントを使う
- 非活性: `text-slate-400` または薄い塗りを使う
- エラー: ここでは特に色に頼りすぎず、テキストと境界の明瞭さを優先する

## 7. 既存UIの参照基準

現在のアプリで採用されている設計の特徴は、次の構成です。

- [src/App.vue](../src/App.vue): アプリ全体の背景、ローディング画面、メインレイアウト
- [src/components/SidebarPane.vue](../src/components/SidebarPane.vue): スレート系のナビゲーション、折りたたみ、明るい選択状態
- [src/components/EditorPane.vue](../src/components/EditorPane.vue): 入力エリアの明るい面、検索バー、操作ボタンの小さな配色
- [src/components/ModalCreateNote.vue](../src/components/ModalCreateNote.vue): 予定表のような軽いカード UI
- [src/style.css](../src/style.css): 全体の補助アニメーション、背景グラデーションの定義

このテーマに沿って UI を作るときは、上記のコンポーネントの組み合わせをベースにしてください。

## 8. AI への作成ルール

AI が新規画面や部品を生成する場合、以下を守ってください。

1. まずこのテーマドキュメントを参照する
2. 既存コンポーネントの色・角丸・影・余白のトーンを合わせる
3. `slate` と `sky` を中心とした配色に限定する
4. 既存の `tailwind` クラスを優先して使う
5. 新しい色を追加するときは、既存のスケールと整合する範囲に収める
6. だれが見ても「WebNote の画面」であることがわかる設計にする

## 9. 例外と更新ルール

- UI の改修が大きくなり、テーマ自体を変える必要がある場合は、このドキュメントを更新してから実装する
- 色や余白の見直しは、影響範囲を明示して文書に残す
- 画面ごとに異なる見た目を作る場合でも、テーマの基底は維持する

## 10. まとめ

WebNote のデザインテーマは、最初に作った簡潔で明るいスレート×スカイの基調に従うべきです。表面的に見た目だけを整えるのではなく、アプリ全体がノートを書くことに集中できるような「静かな明るさ」を維持することが最重要です。

このテーマを守ることで、AI が新しい画面や部品を作るときも、WebNote として一貫した印象の UI を生成できます。
