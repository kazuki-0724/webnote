リリースノート

WebNote バージョン 0.0.5 の更新内容

リリース日: 2026-09-13 00:00:00

リリース概要

このリリースでは、認証済みユーザーの編集を画面切り替えやページ離脱時に安全に保存できるようにし、ホワイトボードとノートのタイトル編集をより自然にしました。 併せて、初回ロード時のローディング UI を改善し、ノート作成時にタイトルを明示できるようにしています。 これにより、ログイン後の編集体験と保存の安定性が向上しています。

src/App.vue

アプリ全体の認証状態と画面切り替えを制御するルート画面です。

追加

認証確認中のローディングデザインと WebNote 署名ロゴを追加し、初期表示の見た目を整理しました。

変更

ページ非表示時や離脱時に pending save を flush する処理を追加し、ホワイトボードのタイトル更新も store 経由で反映されるようにしました。

削除

なし

src/components/EditorPane.vue

ノートタイトル、本文、ホワイトボード編集をまとめて扱うエディタ領域です。

追加

タイトル入力と本文入力に対する store 更新イベントを紐付け、編集内容がそのまま保存キューへ流れるようにしました。

変更

ノートのタイトル変更と本文変更を同じパターンで同期し、ホワイトボードや通常テキストの切り替え時に不整合が起きにくくしました。

削除

なし

src/components/ModalCreateNote.vue

新規ノート作成時の保存先と種別を選ぶモーダルです。

追加

タイトル入力欄を追加し、ノートとホワイトボードの両方で初期タイトルを設定できるようにしました。

変更

新規作成時のタイトルを store.createNote に渡すように変更し、生成直後のノート名が意図どおり残るようにしました。

削除

なし

src/components/WhiteboardCanvas.vue

別紙の手書きメモやアイデア出しを行うホワイトボード描画コンポーネントです。

追加

ホワイトボード上でタイトルを入力できるテキスト欄を追加し、ノート一覧側の見出しと整合するようにしました。

変更

デフォルト描画モードを pen に変更し、マーカー／消しゴムのサイズと選択中ボタンの見た目を調整しました。

削除

なし

src/composables/useAuth.js

認証状態の初期化、ログイン、ログアウト、ユーザー ID の提供をまとめたコンポーザブルです。

変更

Cookie に依存した認証ガードを撤去し、現在の Firebase ユーザー情報を直接基準にしてセッション同期を行うよう整理しました。

削除

Cooki ベースの認証判定に関する重複処理を削除しました。

src/repositories/notesRepository.js

ノートの取得、保存、削除、購読を担当するデータアクセス層です。

変更

保存時のデータを展開してセットするようにし、ユーザーごとのノート更新が既存データを壊さずに反映されるようにしました。

削除

なし

src/store/notes.js

ノート／フォルダの状態管理とホワイトボード保存を担う Pinia store です。

追加

pendingNoteUpdates と localStorage ベースの保存待ち列を追加し、編集中のデータを 3 秒後にまとめて同期する仕組みを導入しました。

変更

ノート更新を直接 Firestore に落とすのではなく queueNoteUpdate 経由へ統一し、タイトル・本文・ホワイトボード更新が失敗時にも再試行可能にしました。

削除

なし

src/style.css

アプリ全体の共通スタイルとローディング・アニメーションの見た目を定義するグローバル CSS です。

追加

WebNote ロゴ風の署名表示、ローディングカード、点滅アニメーションを追加し、認証待機時の見た目を改善しました。

変更

モバイル表示時のスペースと余白を調整し、ローディング状態が崩れにくいようにしました。

削除

なし
