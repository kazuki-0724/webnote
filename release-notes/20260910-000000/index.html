リリースノート

WebNote バージョン 0.0.4 の更新内容

リリース日: 2026-09-10 00:00:00

リリース概要

このリリースでは、ユーザーごとのノートとフォルダの保存先を分離し、認証済みユーザーごとにデータ同期を行う構造に整理しました。 さらに、ノートの種類としてホワイトボードを追加し、ペン・マーカー・消しゴムを使った手書き入力や他のノート編集 UI との切り替えをサポートしました。 その結果、ログイン後に見えるノート一覧、フォルダ管理、保存先の整合性がより明確になっています。

src/App.vue

アプリ全体の認証状態と画面切り替えを制御するルート画面です。

追加

認証確認中のローディング表示とログイン後のホワイトボード表示制御を追加しました。

変更

ログイン成功時にユーザー ID を使って同期を開始し、未認証時にはノートストアの更新を停止するよう整理しました。

なし

src/components/EditorPane.vue

ノートタイトル、本文、ホワイトボード編集をまとめて扱うエディタ領域です。

追加

ノート種別がホワイトボードのときに専用描画領域を表示し、白紙のメモと図解作成を切り替えられるようにしました。

変更

ホワイトボード用の描画イベントを store に接続し、ブラシ入力と消去処理をエディタ内でそのまま動かすよう調整しました。
