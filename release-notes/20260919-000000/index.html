リリースノート

WebNote バージョン 0.0.7 の更新内容

リリース日: 2026-09-19 00:00:00

リリース概要

このリリースでは、ホワイトボードのツールバーを折りたたみ可能にし、描画ツールの選択やサイズ・カラー調整を軽い操作で利用できるようにしました。 併せて、WebMCP 経由で入力される stroke データを正規化して検証する仕組みを追加し、単一 stroke / 複数 stroke / JSON 文字列の様々な入力に対応させています。 その結果、ホワイトボード描画の操作性が向上し、描画入力の失敗や異常なデータを前段で防ぎやすくなりました。

src/components/WhiteboardCanvas.vue

白紙の描画 UI とツールバー制御を担うホワイトボードコンポーネントです。

追加

ツールバーの開閉状態を追加し、必要なときだけ描画設定を表示するようにしました。

変更

トップに戻るボタン、タイトル入力、描画ツール選択、サイズ選択、色選択、クリア操作を折りたたみ可能なレイアウトに整理し、ホワイトボードの視認性を改善しました。

削除

なし

src/store/notes.js

ノート状態とホワイトボードの保存ロジックを管理するストアです。

追加

描画データを正規化する normalizeSingleStroke と normalizeStrokesInput を追加し、stroke の形式を揃えて保存前に検証できるようにしました。

変更

drawPicture と saveWhiteboardStroke が一貫した stroke 形式を受け取るように変更し、空の点列や不正な入力を早く検出できるようにしました。

削除

なし

src/webMCP.js

ブラウザ上のモデル連携ツール定義と描画入力の補助を担う WebMCP 実装です。

追加

drawPicture ツールが単一 stroke、strokes 配列、JSON 文字列のいずれでも受け取れるようにし、入力形式を自動で変換する処理を追加しました。

変更

stroke 変換ロジックを追加し、対象ノート ID が未指定の場合でも現在選択中のノートへ安全に描画できるよう改善しました。

削除

なし
