リリースノート

WebNote バージョン 0.0.6 の更新内容

リリース日: 2026-09-16 00:00:00

リリース概要

このリリースでは、Vue Router ベースの画面遷移を導入し、認証ゲート・ログイン画面・ホーム画面・ホワイトボード画面を分離して、ログイン後の初期化と遷移を整理しました。 併せて、認証確認中のローディング表示と画面ごとの保存制御を追加し、ホームとホワイトボードの切り替えがより自然になるよう改善しています。 これにより、シングルページのままでも画面責務と認証状態が明確に分離され、操作の見通しが向上しています。

package.json

アプリの依存関係と起動スクリプトを定義するプロジェクト設定です。

追加

Vue Router を依存関係として追加し、画面遷移制御に対応できる基盤を整えました。

変更

ルーティングを前提としたアプリ構成に合わせて、依存関係の整理を行いました。

削除

なし

src/App.vue

アプリ全体のルート表示と初期認証処理を担う最上位コンポーネントです。

変更

従来の内蔵画面切り替えを廃止し、ルートに router-view を置く構造へ変更しました。初期化時に initializeAuth を呼び出し、認証状態の確認を一元化しています。

削除

画面ごとの分岐ロジックと直接的なローディング/ログイン UI を削除しました。

src/main.js

Vue App の起動とプラグイン登録を行うエントリポイントです。

追加

Vue Router をアプリへ登録し、画面遷移を有効化しました。

変更

WebMCP の登録は維持しつつ、起動時に router を使う構成へ統一しました。

削除

なし

src/router/index.js

認証状態に応じた画面遷移とルート定義を管理するルーターです。

追加

/auth、/login、/home、/whiteboard を定義し、認証済みユーザーと未認証ユーザーの導線を分けました。

変更

beforeEach によるリダイレクト判定を追加し、初期ロード時にホームやログインのどちらへ進むべきかを明示しました。

削除

なし

src/components/AuthGate.vue

認証状態が確定するまでの待機画面と遷移判定を担当するゲートです。

追加

auth ルートを作成し、authReady と user の両方が揃った時点で /home または /login に振り分ける判定を追加しました。

削除

なし

src/components/Home.vue

認証済みユーザー向けのメイン画面で、サイドバーとエディタの基準視点を保持します。

追加

ホーム画面を追加し、selectedNote が whiteboard の場合に /whiteboard へ遷移するルールを実装しました。

変更

ページ戻る操作やブラウザ履歴の制御を追加し、ホーム画面から離脱した際にログイン後の流れが壊れないよう整理しました。

削除

なし

src/components/Login.vue

Google ログイン画面とログイン成功時の遷移を担う認証 UI です。

変更

ログイン成功後の遷移先を router.replace('/home') に統一し、ユーザーが認証済みになるとメイン画面へ自然に戻るようにしました。

削除

なし

src/components/Loading.vue

認証状態確認中に表示するローディング UI です。

追加

WebNote の署名ロゴとローディングアニメーション付きの待機ビューを追加し、認証確認中の見た目を整えました。

削除

なし

src/components/WhiteboardPage.vue

ホワイトボード専用画面で描画内容の保存と戻る動作を管理します。

追加

/whiteboard 画面を追加し、選択中ノートの種別が whiteboard である場合の表示と遷移を実装しました。

変更

Back-to-top やタイトル変更のイベントを store 経由で処理するように整理し、ホワイトボード画面からメイン画面へ戻る流れを制御しました。

削除

変更

WebMCP ツールの定義を維持しつつ、アプリのバージョン取得を含むツール群の利用方法を整理しました。
