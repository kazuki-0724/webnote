WebNote バージョン 0.0.8 の更新内容

リリース日: 2026-09-20 00:00:00

リリース概要

このリリースでは、ホワイトボードのツールバーを開閉可能にし、デスクトップとモバイルで使いやすいレイアウトに整理しました。 ペン・マーカー・消しゴムの選択、太さと色の調整、ペンモード切替、色パレットのポップアップ表示を一箇所で扱えるようにし、描画の操作性と見た目の整合性を改善しています。 特に、画面サイズに応じてツールバーが自然に縮むことで、白紙の描画領域を広く保ちながら、必要な時だけツール設定を見られるようになりました。

src/components/WhiteboardCanvas.vue

白紙の描画 UI とツールバー制御を担うホワイトボードコンポーネントです。

追加

ツールバーの開閉状態と、縦横の表示差分に対応するモバイル用／デスクトップ用のレイアウト制御を追加しました。

変更

ペン・マーカー・消しゴムの切替、太さ選択、色選択、ペンモード切替、クリア操作を折りたたみ可能なツールバー内に整理し、画面サイズごとの視認性と操作性を改善しました。
