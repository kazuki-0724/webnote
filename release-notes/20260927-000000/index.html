リリースノート

WebNote バージョン v0.0.10 の更新内容

リリース日: 2026-09-27

リリース概要

フォルダ名の更新機能を追加し、サイドバーからフォルダごとの操作を行いやすくしました。フォルダツリーの展開表示とアクセシビリティを改善し、関連モーダルのファイル名も整理しています。

src/components/CreateNoteModal.vue

ノート作成用モーダルを表示するコンポーネントです。

変更

ModalCreateNote.vue からリネームしました。実装内容に差分はありません。

src/components/DeleteConfirmModal.vue

ノートやフォルダの削除確認モーダルを表示するコンポーネントです。

変更

DeleteModalConfirm.vue からリネームしました。実装内容に差分はありません。

src/components/EditorPane.vue

ノート本文の表示と編集を担うエディタコンポーネントです。

削除

コメントアウトされていた共有状態ラベルの断片を削除しました。

src/components/Home.vue

ホーム画面の編集領域と各種モーダルを構成するコンポーネントです。

変更

フォルダ名更新モーダルを画面に追加し、リネーム後のモーダルファイルを参照するようにしました。

src/components/ShareConfirmModal.vue

共有操作の確認モーダルを表示するコンポーネントです。

変更

ShareModalConfirm.vue からリネームしました。実装内容に差分はありません。

src/components/SidebarPane.vue

フォルダとノートの一覧、およびサイドバー操作を表示するコンポーネントです。

変更

フォルダごとのノート作成・名称更新・削除操作を整理し、ノート数表示、展開状態のアクセシビリティ属性、展開アニメーションとスクロール表示を改善しました。動きを抑える設定にも対応しています。

src/components/UpdateFolderNameModal.vue

フォルダ名の更新操作に使うモーダルコンポーネントです。

追加

フォルダ名入力用のモーダルを追加し、store の更新操作と連携しました。

src/components/WhiteboardPage.vue

ホワイトボード画面と関連する操作コンポーネントを構成します。

変更

共有確認モーダルのリネームに合わせて import 先を更新しました。

src/repositories/folderRepository.js

Firestore 上のフォルダデータの読み書きを担うリポジトリです。

変更

Firestore の updateDoc を使って、指定したフォルダの name を更新する処理を追加しました。

src/store/notes.js

ノート、フォルダ、モバイル画面の状態と操作を管理する store です。

変更

フォルダ名更新モーダルの状態・開閉操作・更新処理とフォルダ取得処理を追加しました。削除確認後にモバイル表示をサイドバーへ戻すようにしました。
