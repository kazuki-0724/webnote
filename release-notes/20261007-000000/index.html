リリースノート

WebNote バージョン v0.1.2 の更新内容

リリース日: 2026-10-07

リリース概要

共有ノートの読み込み中・不存在時の表示と、ノート切替時の非同期更新制御を改善しました。サイドバーの表示を調整し、使用されなくなった旧ノート一覧コンポーネントを削除しています。

src/components/SharedViewer.vue

共有リンクからノートやホワイトボードを表示するコンポーネントです。

追加

共有ノート取得中のスケルトン表示と、共有対象が存在しない場合の案内表示を追加しました。

変更

共有 ID の監視を明示的な watch に変更し、リクエスト世代を使って古い取得結果や購読通知の反映を抑制します。切替時・破棄時に購読を解除し、取得処理の失敗も捕捉するようにしました。

src/components/SidebarPane.vue

フォルダとノートの一覧、およびサイドバー操作を表示します。

変更

サイドバーの背景透過やフォルダ行・ノート一覧の余白を調整し、新規フォルダ・ログアウトボタンに立体的な hover / active 表示を加えました。

src/components/ListPane.vue

フォルダ選択中のノート一覧を表示していた旧コンポーネントです。

削除

旧ノート一覧コンポーネントを削除しました。
