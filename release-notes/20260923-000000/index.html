リリースノート

WebNote バージョン 0.0.9 の更新内容

リリース日: 2026-09-23 00:00:00

リリース概要

このリリースでは、ノートやホワイトボードを共有リンクで公開し、URL から閲覧できる共有機能を追加しました。 共有状態の管理、共有 URL の生成、共有中ノートの表示ルートと閲覧画面を合わせて導入し、既存のノート編集体験を壊さずにブラウザ上で簡単に共有できるようにしています。 併せて、共有専用ビューアと共有トークンのハッシュ生成を追加し、URL ベースの閲覧とアクセス制御の入口を整えました。

src/store/notes.js

ノートとホワイトボードの状態管理、共有状態の判定、保存処理をまとめて扱うストアです。

追加

共有ダイアログの状態管理、共有の開始・停止処理、共有状態の参照と共有 URL 生成を追加しました。

変更

ノート選択時に共有状態を自動確認し、既存の保存・タイトル更新・選択状態管理と連携するように整えました。

削除

なし

src/repositories/sharedRepository.js

共有対象のノートを Firestore から取得・保存・削除する共有レポジトリです。

追加

共有 ID によるノート取得、共有データの登録、削除、共有状態の確認を実装しました。

変更

ユーザー ID とノート ID を基にして共有用ドキュメントを結び付け、閲覧画面で再利用可能な取得 API を整備しました。

削除

なし

src/utils/shareToken.js

共有 URL の識別子を生成し、ユーザー ID とノート ID を安定した文字列へ変換するユーティリティです。

追加

FNV-1a ベースのトークン生成関数を追加し、共有時の URL に使う識別子の一貫性を持たせました。

変更

共有リンクの生成と検証の土台として使えるように整備しました。

削除

なし

src/router/index.js

共有ページへのルーティングと認証ガードの制御を担うルーター設定です。

追加

/shared-viewer ルートを追加し、ログイン状態に依存しない閲覧画面を導入しました。

変更

共有ビューアの前提で beforeEach の認証チェックを調整し、公開閲覧を許可するようにしました。

削除

なし

src/components/ShareModalConfirm.vue

共有設定を表示し、共有 URL のコピーと共有/停止の操作を行うモーダルです。

共有されていないノートの共有開始、共有中の URL 表示とコピー、共有の停止操作用の UI を追加しました。

変更

src/components/SharedViewer.vue

追加

変更

src/components/DeleteModalConfirm.vue

変更

src/components/Home.vue

ホーム画面のサイドバー、エディタ、各種モーダルを組み合わせるコンポーネントです。

変更

ユーザー情報とログアウトイベントを SidebarPane に渡し、共有モーダルを追加しました。重複していたユーザー表示と画面幅監視処理を削除しました。

src/components/SidebarPane.vue

フォルダとノートの一覧、検索、ユーザー操作を表示するサイドバーです。

追加

ユーザー名とログアウト操作をサイドバー下部にまとめたアカウント領域を追加しました。

変更

src/components/WhiteboardCanvas.vue

ホワイトボードの描画領域と描画ツールバーを制御するコンポーネントです。

追加

変更

描画面の背景色とペンの初期・選択太さを調整し、ツールバーを閉じた状態でも開閉操作の領域を保つようにしました。モバイル幅でのツール配置も調整しました。

使用されていない手書きモード選択肢とゴミ箱アイコン定義を削除しました。

src/repositories/notesRepository.js

Firestore 上のノートの取得、購読、作成、更新、削除を担うリポジトリです。

削除

使用されていない FIRESTORE_COLLECTIONS の import を削除しました。

src/utils/noteUtil.js

変更
